Major

Real CVE Detection — 70+ Applications

SimpleAudit now queries the NIST National Vulnerability Database (NVD) for every installed application — the same database ConnectSecure and enterprise scanners use. Instead of checking 15 hardcoded apps, we now check 70+ including Chrome, Zoom, Adobe, Teams, WinRAR, Java, Python, VPN clients, and more.

  • New NVD CVE lookup — real CVE IDs, CVSS scores, and descriptions for every matched app version
  • New 70+ application CPE mappings — Chrome, Zoom, Adobe Acrobat, Teams, Firefox, 7-Zip, VLC, WinRAR, OpenVPN, Cisco AnyConnect and more
  • New CVSS score + severity in every CVE finding — shows exactly how critical each vulnerability is
  • Improved 7-day local cache — repeat scans are instant, no re-querying the same version twice
  • Improved CVE findings now feed into the risk score and remediation recommendations list

Security

Security Hardening — 11 Fixes

Deep security audit identified 26 issues. 11 fixed and deployed. Highlights below.

  • Security 2FA codes now use cryptographically secure generation (replaced predictable random)
  • Security Constant-time secret comparison on all token checks — prevents timing attacks
  • Security HSTS header added — forces HTTPS on all connections
  • Security Login rate limited to 5 attempts/minute — brute-force protection
  • Fixed Authorization check on company edit — prevents users accessing other accounts
  • Improved Database indexes on 4 high-query columns — faster portal across the board
